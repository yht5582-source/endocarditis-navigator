# 心內膜炎治療導航

成人感染性心內膜炎臨床決策輔助。繁體中文，支援手機、逐步推導、三個示範病例、文字摘要與列印。以 AHA 2026 科學聲明為主，揭露 ESC 2023、IDSA 與藥品仿單的差異。

## 使用

開啟 GitHub Pages 後，按六步填入情境：急症與手術 → 診斷 → 病原 → 腎臟安全 → 療程 → 出院轉換。可直接點步驟回看。未知資料不視為陰性；警示持續顯示，休克／難治心衰竭立即啟動團隊評估。

- 藥物顯示成人正常腎功能參考方案；AKI、HD、PD、CRRT／PIRRT 須補清除參數、TDM 與藥師核定，未自動開立個別劑量。
- AHA Table 2 的鏈球菌 MIC 與正文差異已揭露；ceftriaxone MIC >0.5 mg/L、敏感性未知或邊界值時停止自動單藥建議。
- 療程以第一次持續轉陰血培養的採樣日為第 1 天；適用一般細菌的 AHA 累計療程，術後至少再 14 個完整日。黴菌、轉移感染或未控制感染源不給自動停藥日。AHA 與 ESC 術後規則不同，須團隊選定依據。
- 口服初篩採 Table 5／POET 日數與實驗室門檻，並添加保守的臨床安全條件。通過代表可討論，仍需逐藥 MIC、交互作用及實際方案核定。
- Oritavancin 給藥後 120 小時內禁用靜脈 UFH；無法用替代凝血檢驗取消禁忌。
- 全部資料只留在記憶體，沒有分析追蹤、後端或 localStorage。重新整理會清空；下載的摘要由使用者自行保管。不要輸入病人識別資料。

## 查證

完整 [修訂對照](docs/corrections.md) 及網頁「文獻依據」。原始聲明與指引連結列在 `data.js`，不重製原文圖表。AHA 2026 是無正式 COR／LOE 的科學聲明；不冒充院內核定指引。

## 維護與測試

無框架依賴或建置步驟。使用靜態 HTTP 伺服器（ES modules 不能以 file:// 開啟）。

```sh
npm run check
npm test
python3 -m http.server 8000
```

`engine.js` 為可獨立測試的推導邏輯，`data.js` 為文獻／修訂／教學病例，`app.js` 為表單與輸出，`style.css` 為響應式樣式。`tests/engine.test.js` 檢查未知資料、轉換條件門檻、MIC 矛盾、腎病／UFH、術後療程與急症。

GitHub Pages：Deploy from a branch → main → /(root)。每次內容更新需重新查證主來源並執行測試。
