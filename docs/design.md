# 設計與實作範圍

使用者授權查證、增刪並製作逐步治療網頁，建立新的 yht5582-source repo。醫療人員由情境推導下一步；非自動確診或院內已核定處方。

採無建置步驟的靜態 HTML／ES modules，分開證據資料、純函數推導與介面；不收集病人身分、不持久化輸入。白底深綠字、teal 強調、左側六步导航，手機折成三欄兩列，窄手機表單一欄，判斷區隨輸入更新。

所有欄位預設未知／空白；永遠區分資料不足與陰性。全局急症提示不因切換步驟隱藏。正常腎功能參考藥物與個別劑量分開；不明 MIC 分支安全停止。轉口服與停止治療都不以資料缺漏推導通過。

實作順序：主來源全文查證 → 修訂資料與來源 → 推導函數 → 六步介面、三例與摘要 → 單元測試 → GitHub repo、Pages → 線上桌面與手機驗證。

必要驗證：未知資料、CRP 嚴格小於、TEE 2 天、術後 7 天、MRSA／VRE 非 POET、BMI 上限、MIC 矛盾、HD／AKI／UFH、術後 14 天與不可自動停藥例外。以實際網站驗證示範載入、步驟修改、修訂／文獻頁、下載與手機溢出。
